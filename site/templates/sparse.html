Limits

What the numbers above do not cover.

  • The gate scores short chunks, so it cannot see cache rounding that builds up deep in a long context. Needle retrieval at the deep contexts is the guard, not a proof.
  • The weight quant and the cache are not separated. The whole build reads {{ m.num('sparse.quality.mean_kld') }}; the quant's own share is not isolated.
  • {{ m.num('sparse.facts.hc_tensors') }} gate tensors are cast at conversion. That cast is interim and its cost is inside every number here.
  • One machine. Nothing has been measured on another card, CPU or RAM size.
  • No KLD gate has been run on Strata here, so the speed comparison is speed only.
