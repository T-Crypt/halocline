Limits

What the dense numbers do not cover.

  • Full context is not shipped. The {{ v('dense.context.int8.label') }} and {{ v('dense.context.fp16.label') }} caches do not fit; the low-bit arm is on a branch and its cost is a short-chunk gate.
  • Depth KLD has not run. The gate scores short chunks, so cache rounding at depth is unmeasured.
  • NInfer's KLD and a like-for-like decode run are open. The prefill comparison is the only same-depth speed reading.
  • The weight quant and the cache are not separated. The whole build reads {{ m.num('dense.quality.arms.halo_q4kxl_int8.quality.kld_mean') }}.
  • One prompt on the load check, one machine for every number.
